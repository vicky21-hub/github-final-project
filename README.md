# Simple Interest Calculator

This project is a simple interest calculator.

## Formula
Simple Interest = (P × R × T) / 100

Where:
P = Principal amount
R = Rate of interest
T = Time (in years)

## Example
If P = 1000, R = 5%, T = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100
